How it works

Medaffin segments the certificate with SAM 3.1 and reads it with Muse Spark. It sends only the crops and metadata to the issuer's paid lookup. The issuer answers 402 with a price. Medaffin's agent checks its case budget in code, then asks Muse Spark Open whether the lookup is worth it, signs an Ed25519 voucher and retries. The issuer charges atomically, near-matches against certificates it segmented with SAM 3.1 when it issued them, and signs the result. If the issuer fails, the credits are refunded exactly once.
